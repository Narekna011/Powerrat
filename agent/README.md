# Powerrat Agent

Агент для мониторинга с явным согласием пользователя.

## Особенности

✅ **Диалог согласия** при первом запуске  
✅ **Видимый индикатор** в системном трее  
✅ **Кнопка отключения** мониторинга  
✅ **Прозрачность** - пользователь видит, что записывается  

## Установка

```bash
cd agent
npm install
```

## Запуск

```bash
npm start
```

## Переменные окружения

```bash
SERVER_URL=ws://your-server.com:8080
AGENT_TOKEN=your-secret-token
```

## Как это работает

1. **При первом запуске** показывается диалог согласия
2. **После согласия** агент минимизируется в трей
3. **В трее** видна иконка с статусом (🔴 включен / ⚪ выключен)
4. **Правый клик на трей** - меню управления
5. **Кнопка "Дадарцнել"** - остановить мониторинг

## Команды сервера

Сервер может отправлять команды:
- `screen_start` - начать снимать экран
- `screen_stop` - остановить
- `webcam_start` - включить вебкамеру
- `webcam_stop` - выключить
- `audio` - записать 10 секунд аудио
- `all_stop` - остановить всё

## Безопасность

- Требует явного согласия пользователя
- Показывает постоянный индикатор в трее
- Пользователь может отключить в любой момент
- Конфиг сохраняется локально
